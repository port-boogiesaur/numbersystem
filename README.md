# Number System Converter and Arithmetic Calculator

![Electron](https://img.shields.io/badge/Electron-Desktop_App-47848F?logo=electron)
![JavaScript](https://img.shields.io/badge/JavaScript-ES6-F7DF1E?logo=javascript&logoColor=black)
![HTML5](https://img.shields.io/badge/HTML5-E34F26?logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?logo=css3&logoColor=white)

A desktop application built with **Electron, HTML, CSS, and JavaScript** that converts numbers between different number systems and performs arithmetic operations on values with different bases.

## Features

- Convert numbers between:
  - Binary (Base 2)
  - Octal (Base 8)
  - Decimal (Base 10)
  - Hexadecimal (Base 16)
- Accept multiple input numbers with selectable bases.
- Perform arithmetic operations:
  - Addition
  - Subtraction
  - Multiplication
  - Division
- Desktop application using Electron.
- Simple calculator-style user interface.

## Technologies Used

- Electron
- JavaScript
- HTML5
- CSS3
- Node.js

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/port-boogiesaur/numbersystem.git
   ```

2. Open the project folder:

   ```bash
   cd numbersystem
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Run the application:

   ```bash
   npm start
   ```
